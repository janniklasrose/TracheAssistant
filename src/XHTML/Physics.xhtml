Selecting the appropriate physics models

  • Space:
    • (x) Three Dimensional
    • ( ) ...
  • Material:
    • (x) Gas
    • ( ) Multi-Component Gas
    • ( ) Multiphase
    • ( ) ...
  • Flow:
    • (x) Coupled Flow
    • ( ) Segregated Flow
    • [both of these enable the "Gradients" model]
  • Equation of State:
    • ( ) Constant Density
    • ( ) Ideal Gas
  • Set the physics air continuum.
    Models: 3D, Ideal Gas, Segregated Flow, Gravity, Turbulence
    • Set the time model to steady or unsteady.
      Steady: Sets steady and asks user for number of iterations.
      Unsteady: Sets implicit unsteady and asks user for time step, inner iterations, and maximum physical time.
    • Set the segregated flow model to isothermal or non-isothermal.
      Isothermal: Constant temperature throughout the domain.
      Non-isothermal: Temperature is a variable, and radiation is enabled.
    • Set the turbulence model to RANS_ke or RANS_kw.
      RANS_ke: RANS k-epsilon.
      RANS_kw: RANS k-omega.
