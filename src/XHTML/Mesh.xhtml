Generating the mesh

  • Create a part mesh operation.
    Recommended: Automated Mesh with the models Surface Remesher, Polyhedral Mesher, Prism Layer Mesher.
  • Experiment with mesh settings.
    Recommended: Use the Intersect operation to test the mesher on small regions of interest first.
  • Generate the surface mesh.
    Explanation: Generates the surface mesh and saves the simulation.
  • Run the volume mesher ...
    • locally.
      Explanation: Executes the meshing pipeline and saves the simulation.
    • remotely.
      Explanation: Creates a meshing macro (.java) file and a batch job submission command.
  • Perform mesh diagnostics.
    Explanation: Runs the native mesh diagnostics, adds quality thresholds, and creates scenes.
